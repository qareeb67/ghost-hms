# 🏥 Ghost HMS (Hospital Management System)

Ghost HMS is a secure, scalable Hospital Management System backend built with Node.js, Express.js, PostgreSQL, and JWT Authentication.

The system is designed to help hospitals manage patients, doctors, appointments, medical records, emergency cases, laboratory requests, billing, medicines, and offline synchronization through a RESTful API.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Ghost-HMS.git
```

Install dependencies

```bash
cd server
npm install
```

Create your environment file

```
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret
```

Run the server

```bash
npm start
```

Ghost HMS includes an Offline Sync Queue.
